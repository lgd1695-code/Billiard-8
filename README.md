# Billiard 8 – Game Bola 8 (HTML/CSS/JS satu file)

Game pool bola 8 tanpa library dan tanpa aset luar (grafik via canvas, suara via WebAudio).
Lisensi: CC0 / domain publik.

## Deploy ke GitHub Pages
```bash
git init
git add index.html README.md
git commit -m "Billiard 8"
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPO.git
git push -u origin main
```
Lalu di GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
Game aktif di `https://USERNAME.github.io/NAMA-REPO/`.
